# Обзор декоров: структура, функции и управление

Декоры в системе PlanPlace представляют собой текстуры, которые используются для визуального отображения материалов в мебельном производстве. Ранее вся информация о материалах хранилась в разделе декоров, но из-за отсутствия данных о физических носителях и ограниченной гибкости, была проведена архитектурная переработка. Сейчас декоры выделены в отдельный раздел и выполняют функцию текстур, используемых для визуализации фасадов (особенно рамок и МДФ-пластей), стен и пола.

**Структура и управление:**
- Декоры организованы в виде таблицы с возможностью добавления, редактирования, скрытия и удаления.
- Категории декоров могут иметь иерархическую структуру с несколькими уровнями.
- Управление включает массовое добавление, импорт и экспорт в формате Excel (XLSX).
- Есть возможность добавлять декоры из системного каталога или загружать несколько декоров одновременно через ZIP-архив.
- При массовом добавлении система автоматически распознает названия файлов и распределяет декоры по категориям.
- В таблице декоров присутствуют поля: название, артикул, категория, видимость в конструкторе, порядок отображения, иконка (редко используется).

**Особенности:**
- Декоры напрямую участвуют в визуализации фасадов, стен и пола.
- В других местах используются опосредованно через плитные материалы, кромки и столешницы.
- Артикул декора важен для ценообразования фасадов и должен использоваться аккуратно, так как изменение артикула может нарушить связь с прайс-листом.

# Массовое добавление и импорт декоров

Для удобства работы с большим количеством декоров предусмотрены следующие инструменты:

- **Добавление из каталога** — позволяет добавить целую папку с подкатегориями из системного каталога.
- **Добавление нескольких декоров** — загрузка ZIP-архива с файлами текстур.
- При загрузке архива можно задать параметры отображения для всех текстур сразу: шероховатость, металличность, прозрачность, способ повторения (растяжение, зеркалирование).
- Система автоматически распознает названия файлов и распределяет декоры по категориям.
- Рекомендуется создавать категории заранее для правильного распределения.
- Для оптимизации работы с текстурами рекомендуется использовать форматы JPEG и PNG, так как BMP слишком тяжелый, а WP (WebP) поддерживается частично.
- Размеры текстур должны быть одинаковыми по разрешению для корректного отображения.
- Для массовой обработки текстур можно использовать сторонние инструменты, например, Microsoft Power Tools, для изменения размера и оптимизации веса файлов.

# Технические параметры текстур: форматы, разрешение, бесшовность

- **Форматы:** Основные поддерживаемые форматы — JPEG, PNG, WP (WebP). BMP не рекомендуется из-за большого размера.
- **Разрешение:** Текстуры должны иметь одинаковое разрешение для корректного отображения. Размеры указываются в пикселях, а в настройках отображения — в миллиметрах (реальная ширина и высота).
- **Бесшовность:** Очень важна для текстур с повторяющимся рисунком (например, дерево, мрамор). Бесшовные текстуры позволяют избежать видимых швов при масштабировании на больших поверхностях, что улучшает визуальное восприятие.
- **Оптимизация:** Для работы в браузере и на маломощных устройствах рекомендуется оптимизировать текстуры, чтобы не перегружать систему и не замедлять работу.

# Настройка отображения текстур: шероховатость, металличность, прозрачность

- **Шероховатость (Roughness):** Определяет степень матовости или глянцевости поверхности.
  - Значение 0 — полностью глянцевая поверхность с яркими отражениями.
  - Значение 1 — полностью матовая поверхность, поглощающая свет.
  - Обычно подбирается индивидуально под тип материала.
- **Металличность (Metalness):** Определяет, насколько поверхность выглядит металлической.
  - Значение 0 — неметаллическая поверхность.
  - Значение 1 — полностью металлическая поверхность с характерным блеском.
- **Прозрачность (Opacity):** Коэффициент прозрачности материала.
  - Значение 0 — полностью прозрачный.
  - Значение 1 — полностью непрозрачный.
  - Используется для стекол, пластиков и других полупрозрачных материалов.
- Настройки применяются как к отдельным текстурам, так и массово при загрузке архивов.

# Работа с картами нормалей, шероховатости и прозрачности

- **Карта нормалей (Normal Map):** Используется для визуального искажения поверхности без изменения геометрии, создавая эффект рельефа.
  - Представляет собой изображение с оттенками серого, где плотность линий указывает на высоты и углубления.
  - Позволяет создавать реалистичные блики и тени на плоских поверхностях.
- **Карта шероховатости (Roughness Map):** Определяет локальные вариации матовости и глянца на поверхности.
  - Позволяет создавать участки с разной степенью блеска, например, имитируя лаковые покрытия на отдельных участках декора.
- **Карта прозрачности (Opacity Map):** Определяет, какие участки материала прозрачны, а какие — нет.
  - Используется для создания эффектов решеток, рельефного стекла и других материалов с частичной прозрачностью.
- Все карты загружаются как отдельные изображения и накладываются на основную текстуру для более сложной визуализации.

# Особенности работы с плитными материалами: структура, свойства и ценообразование

- Плитные материалы — это листовые материалы (ЛДСП, ХДФ, зеркало, стеновые панели, шпон и др.), которые имеют физические размеры и свойства.
- В системе плитные материалы представлены параллелепипедами с текстурами и параметрами отображения, аналогичными декорам.
- Связь с кромками: каждый плитный материал привязан к набору кромок, которые могут использоваться для отделки торцов.
- Толщина материала фиксируется и не меняется пользователем, так как это технологический параметр.
- Ценообразование плитных материалов может осуществляться тремя способами:
  1. Ручной ввод цены.
  2. Цена за категорию материала.
  3. Привязка цены по артикулу из прайс-листа (рекомендуется для крупных производств).
- Для удобства работы с плитными материалами предусмотрены группы материалов — объединения нескольких плитных материалов для удобного переключения в конфигураторе (например, ЛДСП и ЛМДФ для корпуса).

# Группировка материалов и их применение в конфигураторах

- Группы материалов позволяют объединять несколько плитных материалов в одну логическую группу.
- В конфигураторе модуля можно назначить группу материалов, из которой дизайнер сможет выбирать конкретный материал.
- Пример: группа "Корпус" может включать ЛДСП и ЛМДФ, что позволяет переключать материалы на корпусных деталях.
- Группы материалов используются также для витрин, где могут сочетаться ХДФ, стекло и зеркало.
- Группы имеют название, ключ (автоматически генерируется), переключатель видимости и список доступных материалов.
- Удаление групп требует осторожности, так как это может привести к неработоспособности модулей и необходимости перенастройки.

# Импорт, экспорт и массовое редактирование плитных материалов

- Импорт плитных материалов возможен из декоров, что позволяет быстро наполнить базу.
- При импорте можно задать несколько размеров (толщин) для одного материала.
- Экспорт и импорт плитных материалов осуществляется в формате XLSX с возможностью массового редактирования:
  - Поля: ID, видимость, порядок, категория, название, артикул, привязка к кромке, размеры, цена, способ расчёта цены.
- Удаление конкретных вариантов толщин плитных материалов происходит при удалении соответствующих строк в таблице.
- Массовое изменение параметров (например, видимости, категории, кромок) возможно через Excel.
- Привязка цен к прайс-листу позволяет централизованно управлять стоимостью материалов и автоматически обновлять цены.

# Работа с кромками и столешницами: настройка и интеграция

- Кромки — материалы для отделки торцов плитных материалов, рассчитываются по погонным метрам.
- Кромки имеют аналогичные плитным материалам параметры: название, артикул, категория, видимость, цена и способ расчёта.
- Каждому плитному материалу рекомендуется привязывать отдельный набор кромок для удобства управления.
- Столешницы имеют схожую структуру с плитными материалами, но дополнительно включают параметры трапеции и комплектующие (соединительные и торцевые планки).
- Столешницы могут автоматически сшиваться при соприкосновении модулей, а при необходимости разрезаться с добавлением комплектующих.
- Импорт и экспорт кромок и столешниц аналогичен плитным материалам, с некоторыми отличиями в параметрах.

# Интеграция с прайс-листами и автоматизация обновления цен

- Система поддерживает три способа ценообразования:
  1. Ручной ввод цен.
  2. Цены за категорию материалов.
  3. Привязка цен по артикулу из прайс-листа.
- Привязка к прайс-листу позволяет централизованно управлять ценами и автоматически обновлять их через импорт Excel или API.
- Рекомендуется использовать привязку к прайс-листу для средних и крупных производств с большим ассортиментом.
- При обновлении прайс-листа цены автоматически распространяются на все связанные материалы в системе.
- Для интеграции с 1С, CRM или другими системами возможна автоматизация обновления цен без участия человека.

# Рекомендации по управлению и безопасности при удалении данных

- Удаление групп материалов требует особой осторожности, так как это может привести к неработоспособности модулей и необходимости полной перенастройки.
- Перед массовым удалением рекомендуется создавать резервные копии базы данных.
- Удаление отдельных плитных материалов или декоров менее критично — отсутствующие материалы отображаются красным цветом, что облегчает их замену.
- Не рекомендуется произвольно удалять группы без предварительной проверки их использования в модулях.
- Изменение названий и создание новых групп не вызывает проблем и является безопасной операцией.

# Дополнительные технические детали и рекомендации

- Размеры текстур указываются в миллиметрах, при этом предполагается, что 1 пиксель соответствует 1 мм, но это можно корректировать вручную для точного отображения.
- Односторонние материалы (например, пленки) пока не применяются, но предусмотрены для будущих сценариев.
- Для массовой обработки текстур рекомендуется использовать инструменты оптимизации размера и веса файлов.
- Система поддерживает индивидуальные ссылки для каждого клиента, что обеспечивает безопасность и изоляцию данных.
- При работе с проектами и материалами важно учитывать, что проекты и материалы привязаны к конкретной учетной записи и каталогу, что предотвращает несанкционированный доступ и ошибки при переносе проектов между клиентами.
