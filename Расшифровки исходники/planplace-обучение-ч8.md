## 1. Концепция групп материалов и их управление

### Основные понятия  
- **Группа материалов** — набор материалов, используемых для конкретного типа деталей (например, корпусные материалы).  
- При создании нового модуля автоматически добавляется базовая группа материалов (например, корпусная группа).  
- Материалы в группе имеют системный ключ, который можно менять для уникализации и предотвращения конфликтов.  
- Материалы по умолчанию назначаются для деталей при добавлении на сцену.

### Функциональность  
- Возможность добавлять новые группы материалов или копии существующих (с разрывом связи с глобальной группой).  
- Переключатели:  
  - **Локальная группа** — позволяет блокировать изменения материала на глобальном уровне, применимо для вложенных элементов (например, полок), чтобы они не менялись вместе с корпусом.  
  - **Заблокировать изменения** — предотвращает любые изменения материала на уровне модуля или детали.  
  - **По умолчанию** — назначает материал, который будет применяться при первом добавлении детали.

### Применение  
- Автоматическое определение толщины детали по выбранному материалу.  
- Использование толщины материала в расчетах и позиционировании деталей для предотвращения пересечений.  
- Возможность ограничивать доступные материалы по категориям и толщине для разных коллекций изделий.  
- Настройка нескольких групп материалов в одном изделии для разных типов деталей (например, корпус и тонкие панели).

## 2. Элементы и вложенные модули

### Определение  
- **Элемент** — заранее подготовленный компонент, который можно вставить внутрь модуля (например, полка, петля, опора).  
- Элементы имеют тип, название и уникальный идентификатор.  
- Название элемента автоматически подтягивается при добавлении, что облегчает навигацию и идентификацию.

### Особенности  
- Возможность менять тип элемента на другой из той же папки (сменяемый тип элемента).  
- Опция «Не менять элементы по умолчанию» блокирует автоматическую замену элемента при загрузке модуля.  
- Быстрая замена — функция для оперативного переключения элементов (часто используется для дверей, например, смена с правой на левую дверь).  
- Вложенные модули отображаются в структуре и могут быть заменены или скрыты для упрощения интерфейса.

### Пример  
- Петли с разными типами и присадками могут быть заменены по умолчанию или заблокированы от замены.  
- Быстрая замена позволяет избежать ошибок при массовом изменении элементов (например, чтобы двери не стали открываться навстречу друг другу).

## 3. Переменные: мощный инструмент настройки модулей

### Основные возможности  
- Позволяют создавать переключатели, числовые значения и списки без программирования.  
- Управляют видимостью, размерами, положением и другими параметрами модулей и элементов.  
- Переменные бывают локальными (действуют только в конкретном модуле) и глобальными (влияют на весь каталог).  
- Переменные могут быть сгруппированы для удобства управления.

### Типы переменных  
- **Число** — с минимальным, максимальным значением и шагом изменения.  
- **Список** — выбор из заранее заданных значений с текстовыми и системными обозначениями.  
- **Да/Нет** — логический переключатель.

### Особенности работы  
- Переменные могут быть выведены в параметры модуля для настройки дизайнером.  
- Есть возможность условного отображения переменных (показывать только при выполнении определенных условий).  
- Значения переменных могут быть связаны с типовыми размерами, что позволяет автоматически менять параметры при изменении размеров модуля.  
- Переопределение переменных позволяет задавать значения для вложенных модулей и элементов, каскадно распространяя настройки сверху вниз.

### Управление переменными  
- Импорт переменных из вложенных модулей для централизованного управления.  
- Копирование и вставка групп переменных между модулями.  
- Блокировка изменения переменных для предотвращения случайных корректировок.  
- Возможность скрывать переменные из интерфейса для упрощения работы дизайнера.

### Примеры использования  
- Переключатель для включения/выключения цоколя с условием отображения параметров только при включенном цоколе.  
- Управление отступами, положением элементов, видимостью секций и деталей.  
- Автоматическое изменение размеров и параметров в зависимости от выбранных значений переменных.

## 4. Дополнительные инструменты и особенности

### Быстрая замена элементов  
- Позволяет быстро менять элементы одного типа (например, двери) без изменения всего модуля.  
- Можно блокировать быструю замену для предотвращения ошибок при массовом изменении.

### Управление вложенными модулями  
- Вложенные модули отображаются в структуре и могут быть заменены или скрыты.  
- Можно отключить показ вложенных компонентов для упрощения интерфейса.

### Особенности работы с шаблонами и петлями  
- Рекомендуется избегать цикличных вложений (например, петля, содержащая саму себя), чтобы не создавать ошибки.  
- Для фабрик с ограниченными ресурсами предусмотрены шаблоны с минимальными настройками для упрощения расчетов.

### Технические моменты  
- Кэширование браузера может влиять на отображение изменений, рекомендуется очищать кэш при тестировании.  
- В системе реализован поиск по списку переменных с помощью стандартного браузерного поиска (Ctrl+F).
