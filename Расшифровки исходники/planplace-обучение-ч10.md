## Работа с 3D-моделями и вырезами

### Добавление и настройка 3D-моделей  
- 3D-модель добавляется в проект с возможностью управления текстурами и параметрами.  
- Важные элементы: фасад, столешница, цоколь, которые имеют свои особенности позиционирования и взаимодействия.  
- Цоколь и столешница учитываются отдельно от габаритной рамки для предотвращения пересечений с другими элементами.

### Вырезы (Cutouts)  
- Вырез — это 3D-объект, который прорезает все детали, попадающие в его границы, создавая сквозные отверстия.  
- Вырез задаётся параллелепипедом с возможностью обрезки углов и радиусного закругления.  
- Применение: вентиляционные шахты, отверстия под трубы, мойки и т.п.  
- Вырезы имеют параметры: идентификатор, активность, скрытие, привязка к прайс-листу (услуги).  
- Вырезы пока не интегрированы с производственными программами (например, Базис), но ведутся работы по их передаче.  
- Возможность управлять вырезами через переменные для пользователя пока реализована частично.  
- Вырезы могут пересекаться с деталями, если у последних активирован параметр «учитывать в вырезах».

## Аниматор: анимация мебели

### Основные функции аниматора  
- Аниматор — контейнер, который анимирует вложенные объекты с помощью перемещения или поворота.  
- Позволяет создавать эффекты открывания-закрывания дверей, выдвижения ящиков, сдвижных дверей и др.  
- Параметры аниматора: тип анимации (перемещение/поворот), группа (для синхронизации нескольких аниматоров), направление движения, процент выдвижения, угол поворота.  
- Группа позволяет запускать несколько аниматоров одновременно по клику.  

### Особенности работы с петлями и дверями  
- Точка вращения аниматора должна совпадать с точкой шарнира петли (не с углом фасада).  
- Для точного позиционирования аниматора используется имитация корпуса и фасада с помощью дополнительных деталей.  
- Вращение петли — упрощённая модель, в реальности включает сложные кинематические движения (две оси вращения и продвижение).  
- Вложенность аниматоров позволяет создавать сложные конструкции с несколькими степенями свободы (пример — ломаный фасад Aventus с двумя вращениями).  
- Для удобства пользователя создаётся объект «цель для мыши» — виртуальная зона клика, которая объединяет несколько аниматоров и запускает их совместно.  

### Рекомендации и ограничения  
- Избегать цикличных вложенностей аниматоров, чтобы не вызвать рекурсивные ошибки в системе.  
- Использовать один уровень вложенности для петлей и аниматоров.  
- Для выдвижных систем (ящики, скольжение) аниматор проще в настройке, чем для поворотных элементов.

## Размеры и точки прилипания

### Размеры  
- Объект «размер» отображает одну длину (ширину, высоту или глубину) с возможностью задания формулы для вычисления значения.  
- Размеры можно позиционировать и поворачивать, они служат для визуализации и вывода на чертежи.  
- Пример использования: отображение высоты ящиков внутри фасада с возможностью массового включения через глобальную переменную.  

### Точка прилипания  
- Позволяет задавать места и направления «магнитного» прилипания модулей друг к другу.  
- Особенно актуально для угловых модулей, где требуется прилипание к двум стенам и фронтальной части.  
- Точки прилипания можно размещать внутри или снаружи модуля, чтобы управлять поведением при сборке.  
- Используется для точного позиционирования доборных планок, тумб и других элементов, которые должны «зацепиться» за корпус или ножку.

## Вычисляемые значения и шаблоны

### Вычисляемые значения  
- Переменные, которые автоматически вычисляют свои значения на основе других переменных и параметров модуля.  
- Позволяют упростить и централизовать сложные формулы, уменьшить дублирование и повысить читаемость конфигурации.  
- Вычисляются сверху вниз, что важно учитывать при построении зависимостей.  
- Пример: вычисление ширины корпуса модуля в зависимости от общей ширины и других параметров.  

### Шаблоны  
- Позволяют создавать разные конфигурации модуля для различных диапазонов размеров.  
- Каждый шаблон содержит своё дерево конфигуратора с уникальным набором деталей и параметров.  
- Используются для случаев, когда меняется не только размер, но и конструкция (например, количество петель, направляющих).  
- Позволяют избежать громоздких условий и переключателей в одном дереве.  
- Недостаток: при использовании большого количества шаблонов и вложенных элементов возможна нагрузка на систему.  
- Пример: шкафы с разным количеством петель и направляющих в зависимости от размера.

## Настройка меню и пользовательского интерфейса

### Общие принципы  
- Меню делится на три части: левое, верхнее и правое.  
- Настройка меню происходит в личном кабинете, где можно добавлять, удалять и переупорядочивать пункты меню.  
- Можно создавать произвольные пункты меню с вызовом кастомных функций через JSON.  
- Иконки можно выбирать из доступных, но загрузка собственных иконок пока требует поддержки.  

### Основные разделы меню  
- Конструкции (окна, двери, коммуникации) — подключают 3D-модели соответствующих элементов.  
- Материалы — выбор и переключение групп материалов для стен, пола, фасадов, цоколей и 3D-моделей.  
- Каталог модулей — позволяет структурировать мебель по категориям и подкатегориям с возможностью выбора иконок и фильтров.  
- Комплектующие — выводит список дополнительных позиций из прайс-листа, которые можно добавить к проекту.  
- Скидки — настройка произвольных скидок, которые применяются к комплектующим, но не к услугам.  
- Проекты — быстрый доступ к заранее собранным комплектациям мебели.  
- Экспорт — кнопки для вывода проекта в Базис Мебельщик, ASAI.Nest, Cut и другие форматы.  
- Рендеринг — интеграция с коммерческим сервисом E для генерации фотореалистичных изображений проекта.  

### Особенности интерфейса сцены  
- Левая панель — глобальные настройки и меню.  
- Правая панель — настройки конкретного выбранного модуля (размеры, материалы, комплектующие, комментарии).  
- Возможность изменять размеры модулей визуально с помощью прямоугольных контуров.  
- Копирование модулей, поворот, блокировка перемещения и автоповорота.  
- Фильтрация объектов для удобства просмотра.  
- Просмотр проекта в 2D и 3D с возможностью сброса камеры.  
- Экспорт в популярные 3D-форматы (SketchUp, 3D Max, Blender) для дальнейшей визуализации.  
- Сохранение проекта локально с возможностью добавления комментариев.
