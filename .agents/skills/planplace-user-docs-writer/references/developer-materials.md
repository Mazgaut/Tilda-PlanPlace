# Внутренние материалы разработчиков PlanPlace

## Разрешённый источник

`https://planplace.ru/documentation/dev/` — внутренний дайджест задач разработки. Его можно использовать как дополнительный источник для проверки недавно реализованных возможностей PlanPlace и для поиска подходящих скриншотов интерфейса.

Перед использованием материала откройте оглавление и убедитесь, что в поле **«Стадия в BITRIX»** у задачи указано **«Сделаны»**. Материалы со статусами тестирования, разработки, отмены или без статуса не подтверждают поведение для пользовательской справки.

## Границы использования

- Это внутренний источник, а не готовая пользовательская статья. Не публикуйте из него технические формулировки, код, номера задач, статусы, тестовые сценарии, внутренние пути, имена клиентов и сотрудников.
- Используйте материал, чтобы понять итоговое поведение функции. Формулируйте статью заново, простым языком для пользователя без подготовки.
- При расхождении между этим источником и актуальным кодом core_2 источником истины остаётся `master` репозитория `D:\Documents\PP\_Source\_Code\kit`.
- Не превращайте описание исправленного дефекта в инструкцию, если пользователю достаточно знать ожидаемый результат работы функции.

## Скриншоты

- Скриншоты из задач со статусом **«Сделаны»** разрешено использовать, если они ясно показывают пользовательский экран или результат действия и не содержат данных конкретного клиента, персональных данных, ключей или внутренней служебной информации.
- Перед добавлением просмотрите изображение. Скачайте его в `src/assets/<slug-статьи>/` с понятным латинским именем файла; не вставляйте внешнюю ссылку на внутренний сайт.
- Разместите изображение рядом с объясняемым действием, дайте точный русский `alt` и не используйте скриншот как декоративную иллюстрацию.
- Не добавляйте изображения «до исправления», если они показывают ошибочное поведение. Для справки подходит экран корректного результата или настройки.
