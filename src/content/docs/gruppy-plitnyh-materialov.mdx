Группа материалов — это набор плит, которые разрешено использовать для определённой части мебели. Благодаря группам дизайнер на сцене может переключать материал детали (например, менять цвет корпуса), но только в рамках того, что вы разрешили. В этой статье разберём, зачем нужны группы и как их настраивать.

## Зачем нужны группы

Представьте, что у вас корпус шкафа может быть из ЛДСП или ЛМДФ, а витрина — из ХДФ, стекла или зеркала. Если бы дизайнер выбирал материал из всего списка плит, он легко ошибся бы — например, поставил стекло на корпус. Группа решает это: она ограничивает выбор только подходящими вариантами.

Проще говоря, группа — это «меню разрешённых материалов» для конкретной детали или части изделия.

## Как устроена группа

У каждой группы есть:

- **Название** (например, «Корпус», «Фасады МДФ», «Витрина»);
- **Ключ** — системный идентификатор, который генерируется автоматически;
- **Переключатель видимости**;
- **Список доступных материалов** — те плиты, которые войдут в группу;
- **Материал по умолчанию** — тот, что подставится первым при добавлении детали на сцену.

## Локальные и глобальные группы

Группы бывают двух видов, и понимать разницу важно:

- **Глобальная группа** настраивается один раз в разделе материалов и используется во многих модулях. Поменяли состав группы — изменения применились везде.
- **Локальная группа** существует только внутри одного модуля. Она нужна, когда какой-то детали нужен особый, нестандартный набор материалов, не влияющий на остальную базу.

При создании нового модуля автоматически добавляется базовая группа (обычно корпусная). В конфигураторе элемента на вкладке [«Материалы»](/Tilda-PlanPlace/osnovy-konfiguratora/) можно либо привязать модуль к глобальной группе, либо создать копию с разрывом связи — то есть локальную группу.

## Переключатели управления материалом

Внутри модуля у материала есть несколько важных переключателей:

- **Локальная группа** — блокирует изменение этого материала с глобального уровня. Полезно для вложенных элементов: например, чтобы полки не перекрашивались вместе с корпусом.
- **Заблокировать изменения** — запрещает менять материал на сцене вообще. Используется для стандартизации: например, белый ХДФ на задней стенке всех кухонных модулей всегда остаётся белым.
- **По умолчанию** — назначает материал, который подставится при первом добавлении детали.

## Толщина из группы — участвует в расчётах

Когда деталь привязана к группе материалов, система автоматически берёт **толщину выбранного материала** и использует её в формулах и позиционировании. Например, запись `{Корпус}` в формуле означает «толщина материала из группы Корпус». Поэтому при смене материала с 16 мм на 18 мм конструкция сама подстроится и детали не начнут пересекаться. Подробнее о таких формулах — в статье [«Математические вычисления»](/Tilda-PlanPlace/matematicheskie-vychisleniya/).

## Несколько групп в одном изделии

В одном модуле можно использовать несколько групп материалов для разных частей: одна для корпуса, другая для задней стенки, третья для фасадов, четвёртая для тонких панелей. Это позволяет создавать гибкие, «суперконфигурируемые» изделия, где каждую часть можно сделать из своего материала и независимо менять.

## Удаление групп — самая опасная операция

> **Внимание!** Удаление групп материалов — одна из немногих по-настоящему опасных операций. Оно может привести к неработоспособности модулей и необходимости их полной перенастройки. **Перед любым удалением группы обязательно сделайте [резервную копию](/Tilda-PlanPlace/lichnyy-kabinet/).**

При этом создание новых групп и переименование существующих — безопасные операции, их можно делать спокойно. Если что-то всё же сломалось, группы можно пересоздать и сбросить через каталог элементов к значениям по умолчанию.

## Коротко

Группа материалов — это список разрешённых плит для части изделия плюс материал по умолчанию. Глобальные группы используются по всей базе, локальные — внутри одного модуля. Толщина материала из группы автоматически попадает в формулы, поэтому конструкция подстраивается под выбор. Создавать и переименовывать группы безопасно, а вот удалять — только после резервной копии.
