Горячие клавиши и кнопки мыши ускоряют работу на сцене планировщика. В этой статье — только реально работающие сочетания актуальной версии.

## Кнопки мыши

| Кнопка / жест | Что делает |
|---|---|
| **Левая кнопка мыши — клик** по модулю | **Выбрать** модуль: справа откроется панель его настроек (размеры, материалы, комплектующие) |
| **Левая кнопка мыши — перетаскивание** модуля | **Переместить** модуль по сцене |
| **Левая кнопка мыши — перетаскивание** по пустому месту | **Вращать камеру** вокруг сцены (орбита) |
| **Правая кнопка мыши — перетаскивание** | **Сдвинуть камеру** в сторону (панорамирование), не меняя угла обзора |
| **Прокрутка колеса мыши** | **Приблизить / отдалить** камеру (масштаб) |
| **Средняя кнопка мыши (нажатие на колесо) — клик** по фасаду или ящику | **Открыть / закрыть** фасад или ящик (срабатывает анимация) |
| **Alt + левая кнопка мыши — клик** по фасаду или ящику | То же **открывание/закрывание** — удобно на тачпадах и мышах без средней кнопки |

> **Открыть всё сразу.** Открывание всех фасадов модуля одной кнопкой доступно в меню модуля (клик левой кнопкой по модулю → иконка открывания).

## Горячие клавиши

> **Когда клавиши срабатывают.** Горячие клавиши сцены действуют, только когда фокус **не в поле ввода** (не в текстовом поле) и на странице не выделен текст. Если сочетание «не работает» — сначала кликните по пустому месту сцены.

| Клавиши | Что делает |
|---|---|
| **Ctrl + Z** | Отменить последнее действие (undo) |
| **Ctrl + Y** | Повторить отменённое действие (redo) |
| **Delete** | Удалить выбранный (активный) объект |
| **Esc** | Выйти из текущего режима |
| **Ctrl + перетаскивание** модуля | Отключает **примагничивание к стенам и поверхностям** — модуль можно поставить в любое место свободно |
| **Ctrl + Shift + левая кнопка мыши** по модулю | Открывает исходную карточку элемента в личном кабинете в новой вкладке. Доступно владельцу кабинета и сотруднику поддержки |

## Сброс позиции камеры

В меню сцены есть кнопка **«Сброс камеры»** — она мгновенно возвращает камеру в **исходное стартовое положение** (стандартный вид на сцену).

Зачем это нужно: при активном вращении и приближении камерой легко «потеряться» — улететь далеко от кухни, заглянуть внутрь стены или развернуть вид так, что непонятно, где верх. Вместо того чтобы вручную выруливать обратно, нажмите сброс — и вы снова смотрите на сцену как при первом открытии проекта. Особенно выручает клиентов и новичков, которые впервые крутят 3D-сцену.

## Коротко

Мышь: левая кнопка мыши — выбор и перемещение модулей, перетаскивание по пустому месту — вращение камеры, правая кнопка мыши — сдвиг камеры, прокрутка колеса — масштаб, средняя кнопка мыши (или **Alt + клик**) — открыть/закрыть фасад. Клавиши: **Ctrl + Z / Ctrl + Y** — отмена/повтор, **Delete** — удалить выбранный объект, **Ctrl + перетаскивание** — свободная расстановка без привязки к стенам. Для владельца кабинета **Ctrl + Shift + клик** открывает исходную карточку модуля. Если камера «потерялась» — кнопка **«Сброс камеры»** вернёт стандартный вид.
