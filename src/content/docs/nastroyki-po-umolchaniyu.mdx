«Настройки по умолчанию» — это раздел личного кабинета, который задаёт **стартовое состояние сцены**: что увидит дизайнер или клиент, как только откроет планировщик и поставит первый модуль. Какой фасад и его цвет подставятся, какая столешница и цоколь, какой материал стен и пола, какие ручки и карниз — всё это определяется здесь.

> **Почему это важно.** Если не настроить раздел, клиент может увидеть «пустые» или случайные значения, а часть элементов — подсветиться ошибкой. Правильные значения по умолчанию делают первый экран аккуратным и готовым к продаже.

**Где находится:** личный кабинет → меню слева → **«Настройки по умолчанию»**. Внизу страницы — кнопка **«Сохранить»**; после неё не забудьте [выгрузить настройки в конструктор](/Tilda-PlanPlace/lichnyy-kabinet/).

## Из чего состоит раздел

Раздел — это набор блоков, в каждом выбирается значение по умолчанию из соответствующего каталога.

### Плитные материалы по умолчанию

Сами плитные материалы по умолчанию здесь **не выбираются** — раздел отсылает в [«Группы материалов»](/Tilda-PlanPlace/gruppy-plitnyh-materialov/), где для каждой группы задаётся материал и вариант по умолчанию (см. там про каскадный дефолт). То есть «материал корпуса по умолчанию» настраивается в группах, а не в этом разделе.

### Модель фасада по умолчанию

- **Фасад по умолчанию** — какая [модель фрезеровки фасада](/Tilda-PlanPlace/fasady-i-ruchki/) подставляется изначально.
- **Цвет фасада по умолчанию** — декор лицевой стороны (доступные определяются выбранным фасадом).
- **Группа материалов для остеклённых фасадов** — чем по умолчанию заполнены витрины (см. [«Материалы витрин»](/Tilda-PlanPlace/materialy-vitrin/)).

### Модель цоколя по умолчанию

**Цоколь по умолчанию** — какой [цоколь](/Tilda-PlanPlace/cokoli/) ставится под напольные модули изначально.

### Столешница по умолчанию

- **Материал по умолчанию** — [столешница](/Tilda-PlanPlace/stoleshnicy-i-plintusy/), которая подставляется первой.
- **Вариант столешницы по умолчанию** — если у выбранной столешницы несколько вариантов (толщин/форматов).
- **Вариант плинтуса (бортика) по умолчанию** — какой бортик идёт к столешнице.

### Модель ручки по умолчанию

- **Модель ручки по умолчанию** — какая [ручка](/Tilda-PlanPlace/fasady-i-ruchki/) ставится на фасады, у которых не задана своя.
- **Размер** — если у ручки несколько типовых размеров.

### Модель карниза по умолчанию

**Карниз по умолчанию** — какой карниз предлагается для верхних модулей.

### Цвет стен по умолчанию

- **Доступные материалы стен** — какие категории [декоров](/Tilda-PlanPlace/dekory-i-tekstury/) разрешены для стен на сцене (можно несколько).
- **Цвет стен по умолчанию** — какой из них показывается изначально.

### Цвет пола по умолчанию

- **Доступные материалы пола** — какие категории декоров разрешены для пола.
- **Цвет пола по умолчанию** — стартовый материал пола.

> Так вы и ограничиваете выбор клиента (только подходящие отделки стен/пола), и задаёте приятный стартовый вид комнаты.

### Типы фурнитуры по умолчанию

- **Доступные типы фурнитуры** — какие [типы модулей/фурнитуры](/Tilda-PlanPlace/katalog-elementov/) участвуют в наборе по умолчанию.
- Для каждого выбранного типа — **модель по умолчанию** (например, какая петля, направляющая или опора подставляется автоматически).

Это удобно, чтобы при сборке модуля сразу вставала нужная фурнитура без ручного выбора, а на сцене её можно было [быстро заменить разом](/Tilda-PlanPlace/nastroyka-menyu-planirovschika/).

## Как это влияет на работу

- **Дизайнер/клиент** видит на старте именно эти значения — фасад, цвет, столешницу, стены и пол. Чем точнее настройка, тем меньше «доведения напильником» при каждом проекте.
- **Замена на сцене** идёт в пределах того, что вы разрешили (например, только доступные категории стен/пола).
- **Фурнитура по умолчанию** избавляет от ручной простановки петель/направляющих в каждом модуле.

## Порядок настройки

1. Сначала заведите сами элементы (материалы, фасады, столешницы, ручки, карнизы, цоколи, фурнитуру) в их разделах.
2. Откройте **«Настройки по умолчанию»** и в каждом блоке выберите стартовое значение.
3. Для стен/пола укажите **доступные категории**, затем материал по умолчанию.
4. Для типов фурнитуры отметьте доступные типы и задайте модель по умолчанию каждому.
5. Нажмите **«Сохранить»** и [выгрузите настройки в конструктор](/Tilda-PlanPlace/lichnyy-kabinet/).
6. Проверьте на [сцене](/Tilda-PlanPlace/interfeys-sceny/) с жёсткой перезагрузкой: поставьте модуль и убедитесь, что подставились нужные фасад, материал, столешница и т. д.

## Коротко

«Настройки по умолчанию» задают стартовое состояние сцены: фасад и его цвет, материал остеклённых фасадов, цоколь, столешницу с вариантом и плинтусом, ручку, карниз, доступные и стартовые материалы стен и пола, а также типы фурнитуры с моделями по умолчанию. Плитные материалы по умолчанию настраиваются отдельно — в [группах материалов](/Tilda-PlanPlace/gruppy-plitnyh-materialov/). После правок — «Сохранить» и выгрузка в конструктор, затем проверка на сцене.
