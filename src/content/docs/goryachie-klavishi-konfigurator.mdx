В [конфигураторе элементов](/Tilda-PlanPlace/osnovy-konfiguratora/) горячие клавиши ускоряют работу с деревом конструкции, вводом формул и визуальным вращением элементов. Модификатор — **Ctrl** (на Windows) или **Cmd** (на Mac): всё работает кроссплатформенно.

## Дерево конструкции и переменных

Когда выбран узел в дереве (деталь, секция, переменная и т. п.):

| Клавиши | Что делает |
|---|---|
| **Ctrl / Cmd + C** | Копировать выбранный узел |
| **Ctrl / Cmd + X** | Вырезать узел |
| **Ctrl / Cmd + V** | Вставить узел |
| **Ctrl / Cmd + D** | Дублировать узел |
| **Ctrl / Cmd + Пробел** | Открыть окно **«Добавить»** для выбранного узла |
| **Delete** | Удалить выбранный узел. На корне дерева переменных — удалить **все** переменные |

> **Что нельзя копировать.** Корень дерева, а также секции и слоты наполнения через буфер не копируются — для них операции копирования/вставки недоступны.

## Визуальное вращение элемента

У элемента в конфигураторе есть блок **«Поворот»** с углами по осям X, Y, Z. Чтобы крутить элемент мышью прямо в 3D-предпросмотре, нажмите **«Вкл./выкл. оси вращения»** — вокруг элемента появятся цветные кольца осей, а рядом отобразится текущий угол.

- **С зажатым Shift** — вращение идёт **с чётким шагом 90°** (0°, 90°, 180°, 270°). Удобно, когда деталь нужно повернуть ровно «на четверть» без подгонки. Когда угол кратен 90°, метка угла подсвечивается **зелёным**.
- **Без Shift** — вращение на **произвольный угол** (метка становится **оранжевой**, показывая, что угол не кратен 90°).

> **Совет.** Точное значение угла всегда можно вписать вручную в поля **«По оси X / Y / Z»** блока «Поворот» — визуальное вращение и ручной ввод дополняют друг друга.

## Ввод формул и значений

В [полях формул](/Tilda-PlanPlace/matematicheskie-vychisleniya/) конфигуратора:

| Комбинация | Что делает |
|---|---|
| **Ctrl** при перетаскивании параметра/функции в формулу | Подставляет значение со знаком **«−»** (минус) вместо «+». Знак потом можно поменять вручную |

Напомним смежное поведение ввода: **запятая автоматически заменяется на точку** в числах и формулах (см. [«Математические вычисления»](/Tilda-PlanPlace/matematicheskie-vychisleniya/)).

## Коротко

В конфигураторе: **Ctrl/Cmd + C / X / V / D** — копировать/вырезать/вставить/дублировать узел дерева, **Ctrl/Cmd + Пробел** — добавить, **Delete** — удалить. Визуальное вращение: **с Shift — шаг 90°**, без Shift — произвольный угол. В формулах: **Ctrl** при перетаскивании — знак «минус». Горячие клавиши на сцене планировщика — в статье [«Горячие клавиши на сцене»](/Tilda-PlanPlace/goryachie-klavishi-scena/).
