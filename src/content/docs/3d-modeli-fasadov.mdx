Фрезеровка фасада — это **встроенная 3D-модель** (см. [общие требования к встроенным моделям](/Tilda-PlanPlace/3d-modeli-vstroennye/)). Фасад берётся из меню **«Фасады» → «Модели фрезеровки»** и привязывается к модулю; система обрабатывает его **по ключам в названии мешей**. Здесь разобраны нюансы именно для фасадов: чем отличаются простые и сложные фрезеровки, как настраивается текстура и патина.

> Базовые требования (формат `.fbx` 7100+, масштаб 1:1, центр в нуле, UV, нормали наружу, отдельные объекты) — общие для всех встроенных моделей и описаны [здесь](/Tilda-PlanPlace/3d-modeli-vstroennye/).

## Простые фрезеровки

Подходят для фасадов с **прямолинейной геометрией** по всем направлениям — модель можно тянуть без искажений.

- Адаптивный по ширине и высоте меш именуют:

  ```
  v(3)_m(gen)_t(xy)
  ```

- Если фасад меняется и по глубине, добавляют ось `z`:

  ```
  v(3)_m(gen)_t(xyz)
  ```

Ключи материалов: **`gen`** — лицевая сторона, **`back`** — белая обратная сторона.

## Сложные фрезеровки

Если геометрия при изменении размера меняется неравномерно (узор, рельеф), одной адаптацией не обойтись — готовят **линейку вариантов модели** и используют **растягивание** (`s`) вместо адаптации (`t`):

- пропорциональное масштабирование по ширине и высоте:

  ```
  v(3)_m(gen)_s(xy)
  ```

- адаптация по высоте + растягивание по ширине:

  ```
  v(3)_m(gen)_t(y)_s(x)
  ```

- то же с добавлением глубины:

  ```
  v(3)_m(gen)_t(yz)_s(x)
  ```

## Текстура и UV-развёртка

Для текстурированных поверхностей **UV-развёртка обязательна**. В Blender её делают так:

1. Перейти в **ортографический вид** (вид спереди).
2. Выделить всё: **Tab** (режим редактирования) → **A**.
3. Открыть меню развёртки: **U** → **Project from View** (проекция из вида).

Если текстуру нужно повернуть на 90°, добавляют ключ **`r(90)`**:

```
v(3)_m(gen)_r(90)_t(xy)
```

## Патина

Для эффекта **патины** в модели предусматривают отдельную проработку поверхности/материала — патинируемые участки оформляются так, чтобы система могла отобразить состаренное покрытие. Используйте подготовленные примеры ниже как образец.

## Встроенные ключи материалов

Полный список встроенных ключей (`gen`, `glass`, `back`, `black`, `al`, `metall`, `window`, `corpmat`, `facmat`, `mirror`, `topcorpmat`, `botcorpmat`) приведён в статье [«Встроенные 3D-модели: общие требования»](/Tilda-PlanPlace/3d-modeli-vstroennye/#встроенные-ключи-материалов). Если нужного материала нет — задаётся индивидуальный ключ.
