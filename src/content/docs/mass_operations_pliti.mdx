## Где пригодится

Сценарии массовых операций включают переезд с версии 1.0 на 2.0, смену поставщика ЛДСП,
обновление прайса, введение новой толщины, настройку разных типов расчёта и управление
сезонными коллекциями. Каждая операция позволяет обработать множество позиций
одновременно вместо ручного редактирования.

## Массовые операции в интерфейсе

В разделе плитных материалов доступны следующие инструменты:

- **Генерация кромок** — создаёт кромочные ленты для выбранных плит с припуском.
- **Добавление толщины** — добавляет новую толщину ко всем отмеченным плитам.
- **Скрыть/Показать** — управляет видимостью декоров на сцене.
- **Удалить** — удаляет выбранные плиты.

**Важно:** не удаляйте целую папку материала, так как это нарушит привязки в модулях
конструктора. Лучше скрыть содержимое.

## Импорт/Экспорт Excel

Файл `.xlsx` служит шаблоном для работы с плитными материалами в табличных редакторах.
Структура включает три функциональных блока.

**Блок 1: Идентификация**

- Ключ и ID для поиска материала в системе.
- Видимость, порядок сортировки, категория.
- Название и артикул, как у поставщика.
- ID кромочного материала и ключ набора кромок.

**Блок 2: Параметры варианта плиты**

- Название и артикул варианта с толщиной.
- Длина, ширина в мм (стандартные форматы листов).
- Толщина плиты (16, 18, 25 мм и др.).

**Блок 3: Ценообразование**

- Ручная цена за единицу расчёта.
- ID позиции в прайс-листе для автоподстановки.
- Режим привязки цены (ручной, по ID, по артикулу).
- Тип расчёта (р/шт., р/п.м., р/хлыст, р/м², р/м³).

## Сценарий 1. Единая цена на категорию

Для каталогов с 100+ декорами одной толщины используется привязка через прайс-лист:

1. Создать базовую позицию в прайс-листе с артикулом и ценой за м².
2. Экспортировать плитные материалы в `.xlsx`.
3. Отфильтровать по толщине и указать ID прайс-листа для всех строк.
4. Задать тип расчёта `m2` (за квадратный метр).
5. Импортировать изменения и выгрузить в конструктор.

Результат: все плиты 16 мм считаются по цене из одной позиции прайс-листа с возможностью
обновления в одном месте.

## Сценарий 2. Ручной ввод цены

Для малых ассортиментов (10–50 позиций) без внешней системы учёта:

1. Экспортировать таблицу ЛДСП.
2. Для каждой позиции задать тип расчёта `p` (р/шт.).
3. В поле «Ввод цен» указать `m` (ручной).
4. Внести цену за целый лист.
5. Импортировать обратно.

Позволяет комбинировать разные типы расчёта в одной таблице.

## Сценарий 3. Интеграция с учётной системой

Для крупного производства (1000+ SKU) с 1С или БАЗИС:

1. Импортировать декоры с корректными названиями и артикулами.
2. Убедиться, что артикулы варианта совпадают с учётной системой.
3. Задать поле «Ввод цен» = `c` (по артикулу).
4. Подготовить прайс-лист с артикулами и ценами.
5. Импортировать прайс обратно.

Цены обновляются централизованно через прайс-лист или API.
