Фасад — это лицевая, видимая часть мебели: дверцы шкафов, кухонных модулей, ящиков и декоративные панели. Именно фасады формируют образ гарнитура и часто составляют **до 60–70 % стоимости** изделия, занимая при этом лишь около 25 % площади материалов. Поэтому у фасадов отдельная, более тонкая система ценообразования. В этой статье — точные шаги настройки с примерами.

## Почему фрезеровки в одном материале стоят по-разному

Даже у одного материала (например, МДФ) разные фрезеровки имеют разную цену, и это нормально:

1. **Сложность обработки.** Плоскую заготовку станок с ЧПУ фрезерует за минуты, а рельефный рисунок с филёнками или 3D-профилем требует больше времени, частой смены инструмента и точной настройки.
2. **Расход материала и отходы.** Глубокая или фигурная фрезеровка увеличивает обрабатываемую площадь и объём стружки — растёт расход МДФ и износ фрез.
3. **Последующая отделка.** Сложный рельеф труднее шлифовать; при облицовке плёнкой ПВХ нужны более эластичные и дорогие плёнки.
4. **Технологические риски.** Тонкие перемычки, острые углы профиля, радиусы повышают риск брака при прессовании — это закладывается в цену.

## Где настраиваются цены: алгоритм доступа

Цены настраиваются **внутри конкретной фрезеровки**:

1. Перейдите в раздел **«Фасады» → «Модели фрезеровок»**.
2. В списке найдите нужную модель.
3. Нажмите иконку редактирования (**карандаш**) в колонке «Действия».

Внутри редактора фрезеровки есть вкладки: **«Модели»** (какие типы доступны: глухой, витрина, решётка), **«Доступные декоры»** (какие декоры применимы), **«Цены»**, **«Индивидуальные декоры»**, **«Точные размеры фасадов»**.

## Три способа задать цену

Система поддерживает три способа, которые можно комбинировать.

### Способ 1. Цена по категории материала (за м²)

Единая цена для целой категории материалов.

1. В редакторе фрезеровки откройте вкладку **«Цены»**.
2. Выберите тип расчёта **«М2»** (цена за квадратный метр).
3. В таблице укажите цены для каждой категории по типам фасада:
   - **Глухой** — цена для глухих фасадов;
   - **Витрина** — цена для остеклённых;
   - другие типы — в зависимости от того, что доступно для этой фрезеровки (см. вкладку «Модели»).

Категории (например, «Древесные», «Каменные», «Однотонные», «Фантазийные», «Пластик ARPA») настраиваются для каждой фрезеровки на вкладке **«Доступные декоры»** — потому что не к каждой фрезеровке применимы любые декоры (на МДФ-фасады не наносят декоры для ЛДСП, а ЛДСП-панели бессмысленно красить по RAL). Аналогично, при необходимости, задаётся цена кромки в п.м.

**Когда использовать:** стандартный ассортимент. Цена применяется ко всем декорам категории.

### Способ 2. Индивидуальные декоры

Специальная цена для конкретного декора (цвета), даже если на категорию уже задана цена. Нужна, когда внутри категории есть особо дорогие декоры.

1. Откройте вкладку **«Индивидуальные декоры»**.
2. В поле **«Артикул декора»** укажите артикул нужного декора (его можно найти в разделе [«Декоры» → «Список декоров»](/Tilda-PlanPlace/dekory-i-tekstury/) в строке декора).
3. Укажите цены для всех моделей фрезеровки: **Глухой, р/м²**; **Витрина, р/м²** и т. д.
4. Нажмите **«Добавить»**, затем **«Сохранить»**.

**Когда использовать:** премиальные или акционные декоры. Применяется только к указанному артикулу.

### Способ 3. Цена по точным размерам фасада

Фиксированная цена для фасадов конкретных размеров — хорошо для модульных кухонь, где размеры заранее известны.

1. Откройте вкладку **«Точные размеры фасадов»**.
2. Заполните поля:
   - **Ширина (мм)** и **Высота (мм)**;
   - **Тип** — Глухой / Витрина / Решётка;
   - **Артикул декора** — опционально. Если не указан, цена применится ко всем декорам этой фрезеровки с совпадающим размером; если указан — только к конкретному декору;
   - **Название** (например, «Фасад 300×200»);
   - **Артикул** (например, «300-200-f2»);
   - **Ввод цен** — ручной ввод или по артикулу из [прайс-листа](/Tilda-PlanPlace/prays-listy/);
   - **Цена**.
3. Нажмите **«Добавить»**, после всех позиций — **«Сохранить»**.

> **ВАЖНО: учитывайте припуск фасада.** Стандартный припуск — **4 мм** (по 2 мм с каждой стороны), его можно изменить в [глобальных переменных](/Tilda-PlanPlace/globalnye-peremennye/) или в конкретном дверном модуле, где используется объект «Фасад». Размер фасада указывается **с учётом припуска** — то есть меньше проёма.
>
> **Пример.** Нужен фасад на модуль с проёмом (по внешним габаритам) 300×200 мм. В системе указывайте **296×196 мм** (300 − 4 и 200 − 4).

**Когда использовать:** проекты с фиксированными размерами. Размерных рядов бывает много, и их придётся повторять для всех фрезеровок — для этого удобен экспорт/импорт через Excel.

## Приоритет цен

Если на один декор заданы цены несколькими способами, система применяет их в порядке приоритета (от точечного к общему):

1. **Точные размеры**;
2. **Индивидуальные декоры** (наивысший приоритет среди точечных);
3. **Категория материала** (базовый уровень).

> **Не используйте все три способа одновременно** для одного и того же декора. Технически это возможно, но потом будет трудно понять, почему цена не та, что ожидалась.

## Рекомендуемые комбинации

- **Вариант A (простой):** только цена по категории (м²). Для стандартного ассортимента.
- **Вариант B (средний):** категория (м²) + индивидуальные декоры. Базовые цены по категориям и корректировка для отдельных дорогих декоров.
- **Вариант C (продвинутый):** точные размеры с указанием декоров под каждый размер. Для модульных проектов с фиксированными размерами.

## Связь с декорами, наценками и витринами

- Цена фасада привязана к [декору](/Tilda-PlanPlace/dekory-i-tekstury/) через **артикул** — не меняйте артикулы декоров бездумно, иначе цена «слетит».
- К фасадам применима отдельная [точечная наценка](/Tilda-PlanPlace/pravila-rascheta-cen-nacenki/) (категория «Фасад»).
- Цены на материалы витрин теперь работают через [плитные материалы](/Tilda-PlanPlace/plitnye-materialy/) — см. [«Материалы витрин»](/Tilda-PlanPlace/materialy-vitrin/).

## Проверка результата

1. Создайте тестовый проект с фасадами.
2. Проверьте отображение цен в [спецификации](/Tilda-PlanPlace/specifikaciya-i-otpravka-na-raschet/).
3. Сформируйте PDF и проверьте корректность расчётов.
4. При необходимости скорректируйте цены.

## Коротко

Цены на фасады настраиваются внутри каждой фрезеровки («Фасады → Модели фрезеровок → карандаш») тремя способами: по категории материала (за м²), индивидуально по артикулу декора и по точным размерам (с учётом припуска 4 мм — фасад меньше проёма). При совпадении приоритет такой: точные размеры → индивидуальные декоры → категория. Не смешивайте все три способа на одном декоре и проверяйте итог на тестовом проекте.
