## Что даёт учётная запись дилера

Учётная запись дилера позволяет организовать продажи через розничную сеть с различными
наценками на базовую цену. Дилер может продавать в разных городах или каналах продаж,
используя главный каталог и установленное ценообразование.

**После первоначальной настройки дилер может:**

- продавать продукцию под своим брендом и разместить её на своём сайте;
- скорректировать цены через систему наценок;
- получать заявки от своих клиентов на свою почту;
- работать с каталогом поставщика, который предоставил учётную запись.

## Шаг 1. Создание учётной записи дилера

1. Перейдите в раздел **«Пользователи»** в левом меню.
2. Нажмите зелёную кнопку **«Добавить пользователя»**.
3. Заполните поля:
   - **Имя** — название дилера.
   - **Email** — почта дилера.
   - **Роль** — выберите **«Дилер»**.
   - **Наименование аккаунта** — уникальный alias.
4. Нажмите кнопку **«Добавить»**.

**Важно:**

- На указанный email автоматически отправляется письмо с логином и паролем.
- Вверху страницы отображается количество подключённых аккаунтов (например, «3 из 10»).

## Шаг 2. Получение доступа (для дилера)

1. Проверьте email, указанный при регистрации.
2. Найдите письмо с темой **«Для Вас активирован доступ в личный кабинет PlanPlace»**.
3. В письме содержатся:
   - **Логин** — ваш email.
   - **Пароль** — автоматически сгенерированный пароль.
   - Ссылка для входа в личный кабинет.
   - Ссылка на сцену конструктора.

**Важно:** если письмо не пришло, проверьте папку «Спам».

## Шаг 3. Настройка основных параметров (брендирование)

1. Перейдите в раздел **«Основные параметры»**.
2. Заполните поля:
   - **E-mail для заявок** — email для входящих заявок (допускается несколько адресов
     через запятую).
   - **Сайт установки** — адрес сайта, где будет размещён конструктор.
   - **Телефон, адрес** — контактные данные для клиентов.
   - **Логотип** — загрузите свой логотип (рекомендуемый размер: 180×180 px).
3. Скопируйте сгенерированный HTML-код конструктора и вставьте его на страницу вашего
   сайта.
4. Нажмите **«Сохранить»** для применения настроек.

## Шаг 4. Настройка наценок (в личном кабинете дилера)

1. Прокрутите страницу настроек до блока **«Наценка (множитель)»**.
2. **Общая наценка** — установите базовый множитель (например, 1 = без наценки, 2 =
   наценка 100%).
3. **Округление** — выберите вариант округления.
4. При необходимости добавьте индивидуальные наценки:
   - Нажмите **«Добавить наценку»**.
   - Выберите категорию.
   - Укажите множитель наценки.
   - При необходимости отметьте **«Не умножать на общую наценку»**.
5. Нажмите **«Добавить»**, затем **«Сохранить»**.

**Пример:**

- Общая наценка: 1 (базовая цена).
- Столешница: множитель 3 (тройная наценка).
- Материал: множитель 2 (двойная наценка).

## Доступные способы округления

- **Нет** — округление отключено.
- **Математическое** — округление до двух знаков после запятой (1.126 → 1.13, 1.124 → 1.12).
- **В большую сторону** — всегда округление вверх (1.126 → 1.13, 1.124 → 1.13).
- **В большую до 10** — округление до десятков вверх (1612 руб → 1620 руб).
- **Фиксировано 2 знака** — округление до двух знаков с фиксированным форматом
  (1.1 → 1.10, 1.126 → 1.13).

## Удаление дилера

Удаление происходит через меню «Пользователи». Напротив нужного пользователя с ролью
«Дилер» нажмите на иконку удаления (корзина) и подтвердите действие. Учётная запись будет
отключена, а все настройки обнулены.
