Эта статья — практические чек-листы для настройки базы под разные модели ценообразования. Распечатайте или держите рядом и отмечайте пункты по мере выполнения, чтобы ничего не упустить. Подробности по каждому шагу — в статьях [«Мебель на заказ»](/Tilda-PlanPlace/scenariy-mebel-na-zakaz/) и [«Модульная / серийная мебель»](/Tilda-PlanPlace/scenariy-modulnaya-seriynaya/).

## Чек-лист: мебель на заказ (себестоимость + наценка)

**Материалы**
- [ ] Каждому плитному материалу задан [тип расчёта](/Tilda-PlanPlace/dostupnye-tipy-raschetov/) (ЛДСП/МДФ — `м²` или `шт.`).
- [ ] Кромкам задан тип `п.м.`.
- [ ] Профилям, трубам, ленте задан `п.м.`; металлопрокату — `хлыст` или `хлыст (п.м.)`; массиву — `м³`.
- [ ] Учтён отход (КИМ): задан [коэффициент отхода, %](/Tilda-PlanPlace/plitnye-materialy/) у вариантов плит (работает для типов шт./п.м./м²/хлыст (п.м.); для шт. — поверх округления до листа). Для **м³** коэффициент не действует — там запас закладывают в цену. Только **одним** способом, без задвоения.

**Цены**
- [ ] Материалы, кромки и фурнитура привязаны к [прайс-листу](/Tilda-PlanPlace/prays-listy/) по артикулам.
- [ ] При большом ассортименте подключена [синхронизация по API/1С](/Tilda-PlanPlace/sinhronizaciya-po-api/).
- [ ] Настроена [общая наценка](/Tilda-PlanPlace/pravila-rascheta-cen-nacenki/); при необходимости — точечные.
- [ ] Настроено округление итоговой цены.

**Модули**
- [ ] У модулей **разрешён** ввод размеров, заданы минимумы/максимумы.
- [ ] Размеры деталей считаются [формулами от родителя](/Tilda-PlanPlace/parametry-formuly-pozicionirovanie/).
- [ ] Толщина деталей берётся из [групп материалов](/Tilda-PlanPlace/gruppy-plitnyh-materialov/).
- [ ] У модуля **нет** прямой фиксированной цены (чтобы не задвоить с материалами).

**Фасады и операции**
- [ ] [Цены на фасады](/Tilda-PlanPlace/nastroyka-cen-na-fasady/) заданы по площади (`м²`).
- [ ] Артикулы декоров стабильны (не меняются).
- [ ] Фурнитура добавлена [позициями прайса](/Tilda-PlanPlace/prays-listy/) к модулям.
- [ ] Операции (сверление, пазы, сборка) учтены через [присадки](/Tilda-PlanPlace/prisadki/)/[пазы](/Tilda-PlanPlace/pazy-i-vyrezy/)/наценку.

**Проверка**
- [ ] Собрано тестовое изделие, цена меняется логично при смене размеров.
- [ ] Спецификация сверена с ручным расчётом.

## Чек-лист: модульная / серийная мебель (фиксированная цена)

**Цены модулей**
- [ ] Каждому модулю задана **прямая фиксированная цена** (см. [«Основы конфигуратора»](/Tilda-PlanPlace/osnovy-konfiguratora/)).
- [ ] У модуля **нет** расчёта по материалам (чтобы не задвоить).
- [ ] Для разных размеров заданы [типоразмеры](/Tilda-PlanPlace/shablony-moduley/) с уникальными артикулами и ценами.

**Размеры и каталог**
- [ ] Ввод произвольных размеров **заблокирован** (в [настройках конструктора](/Tilda-PlanPlace/nastroyki-konstruktora/) или у модуля).
- [ ] [Каталог](/Tilda-PlanPlace/katalog-elementov/) структурирован по коллекциям, есть иконки и короткие названия.

**Материалы и фасады**
- [ ] Настроены [ценовые категории материалов](/Tilda-PlanPlace/pravila-rascheta-cen-nacenki/) (эконом/стандарт/премиум), если есть доплаты.
- [ ] Декоры ограничены по категориям.
- [ ] [Фасады](/Tilda-PlanPlace/nastroyka-cen-na-fasady/) оценены по типоразмерам.

**Серийное производство**
- [ ] Артикулы модулей совпадают с учётной системой.
- [ ] Проверена **уникальность артикулов**.
- [ ] Подключена [синхронизация с 1С/API](/Tilda-PlanPlace/sinhronizaciya-po-api/), если ведёте цены в учёте.

**Проверка**
- [ ] Цена проекта = сумме каталожных цен.
- [ ] Произвольные размеры недоступны.
- [ ] Доплата за категорию материала работает.

## Краткий чек-лист: гибрид (база + допы)

- [ ] Базовая часть (корпус) считается от материалов **или** имеет фиксированную цену.
- [ ] Апгрейды (премиум-фасады, доводчики, техника) — [позиции прайса](/Tilda-PlanPlace/prays-listy/).
- [ ] На апгрейды при необходимости заданы [точечные наценки](/Tilda-PlanPlace/pravila-rascheta-cen-nacenki/).
- [ ] Проверено отсутствие двойного учёта базы и допов.

## Общие правила для любой модели

- [ ] Перед массовыми изменениями цен сделана [резервная копия](/Tilda-PlanPlace/lichnyy-kabinet/).
- [ ] После настройки цены **выгружены в конструктор** (кнопка «Выгрузить настройки в конструктор»).
- [ ] Результат проверен на [сцене](/Tilda-PlanPlace/interfeys-sceny/) с [жёсткой перезагрузкой](/Tilda-PlanPlace/lichnyy-kabinet/).
- [ ] Нигде нет двойного учёта стоимости.

## Коротко

Используйте чек-листы как карту настройки: для заказной модели — материалы с типами расчёта, КИМ, прайс по артикулам, параметрические модули и наценки; для модульной — фиксированные цены, блокировка размеров, категории материалов и артикулы. Для погонного метра и гибрида — короткие списки поверх базовой модели. Главное во всех случаях — резервная копия, выгрузка в планировщик и отсутствие двойного учёта.
